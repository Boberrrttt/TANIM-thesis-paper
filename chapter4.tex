\section{Data Processing and Preparation Results}
This section presents the results of the data processing and preparation procedures applied to the collected datasets. Multiple data sources such as soil sensor readings, environmental data, zoning information, and historical agricultural records were consolidated and transformed into a structured format suitable for analysis.

The primary objective of this phase was to ensure that the dataset is accurate, consistent, and representative of real-world agricultural conditions in Bukidnon. Various techniques such as data integration, cleaning, preprocessing, and feature engineering were applied to improve data quality and usability.

The results discussed in this section demonstrate how raw and heterogeneous data were refined into a reliable dataset that supports effective machine learning modeling and accurate crop and fertilizer recommendations.

\subsection{Data Integration Results}
The data integration phase yielded a structured and machine-readable dataset derived from the Consolidated Soil Info (RSL) 2023--2025 repository. As illustrated in \textbf{Figure \ref{fig:integrated_data}}, the finalized dataset consists of validated soil profiles defined by key agricultural parameters: soil pH, organic matter percentage, and nutrient concentrations of phosphorus and potassium in parts per million (ppm). Following the integration process, irrelevant metadata and unstructured annotations were removed to produce a clean dataset centered on agronomic variables. The processed data was subsequently mapped to a predefined set of ten target crops---including Corn, Tomato, and Cassava---ensuring categorical consistency across the repository.

The resulting dataset is composed of structured entries where each row represents a complete soil profile linked to a specific crop classification. For instance, entries such as RSL-001 through RSL-005 in \textbf{Figure \ref{fig:integrated_data}} demonstrate the alignment of specific chemical properties with zoned target crops like Corn and Eggplant. This structural transformation converted fragmented spreadsheet data into a uniform format suitable for machine learning model training. Ultimately, the integration phase produced a reliable baseline that bridges historical agricultural records with the data structures required for real-time Internet of Things (IoT) sensor simulation.

\subsection{Data Cleaning and Preprocessing Results}
The preprocessing stage resulted in a significantly improved dataset in terms of completeness, consistency, and class distribution. All missing and invalid entries, including non-numeric errors and incomplete sensor readings, were successfully eliminated, producing a fully clean dataset with no null or corrupted values. This rigorous cleaning process ensured that the secondary data ingested from historical records remained structurally consistent with the real-time telemetry captured by the sensor node.

Noise and outlier reduction further enhanced the dataset quality. All numerical features were constrained within realistic agricultural limits, ensuring physically valid values across all parameters. For instance, soil pH values were maintained strictly within the acceptable agronomic range of 3 to 9, preventing the presence of unrealistic or extreme measurements that could skew model convergence. This normalization resulted in a more stable and reliable data distribution, effectively preparing the feature space for gradient-based learning.

A major improvement was observed in the class distribution of the target variables. Prior to preprocessing, the dataset exhibited severe class imbalance, as shown in the original (red) bars in \textbf{Figure \ref{fig:data_augmentation}}, where common crops like Corn significantly outnumbered minority categories such as Ampalaya and Sweet Pepper. This disparity posed a high risk of producing a biased model that favored majority class predictions. After the application of synthetic data balancing, the dataset achieved a uniform class distribution, as illustrated by the augmented (green) bars in \textbf{Figure \ref{fig:data_augmentation}}.

Two ratio-based features were successfully computed: the Phosphorus-to-Potassium ratio ($P\_K\_ratio$) and the Phosphorus-to-Organic Load ratio ($P\_OM\_ratio$). As detailed in \textbf{Table \ref{tab:feature_engineering}}, the $P\_K\_ratio$ evaluates the internal balance between root development and fruiting energy, while the $P\_OM\_ratio$ identifies environments where raw nutrients are inaccessible due to poor soil degradation. These features enable the model to evaluate relative nutrient proportions, which often carry more discriminative power in tropical soil profiles than absolute concentrations alone. 

Furthermore, two interaction features were generated: the pH-Gated Nitrogen Bio-availability ($OM\_pH\_interaction$) and the pH-Gated Potassium Bio-availability ($K\_pH\_interaction$). These variables mathematically encode the dependency of nutrient uptake on soil acidity. Specifically, these terms simulate real-world Potassium fixing limitations and Nitrogen conversion mediated by microbiological activity.

The final set of eight features served as the basis for model training. Feature importance analysis via LightGBM split gain confirmed that the engineered features contributed meaningfully to the system's predictive capability, collectively accounting for approximately 42.4\% of the total feature importance. Notably, the $K\_pH\_interaction$ feature ranked as the third most important variable overall at 15.1\%, surpassing two raw soil measurements. The $P\_OM\_ratio$ (10.0\%) and $P\_K\_ratio$ (9.3\%) further demonstrated that relative nutrient proportions carry substantial power for crop classification. Overall, the feature engineering process produced a richer and more informative dataset that enabled the classifier to capture complex agronomic relationships.

\section{Machine Learning Model Performance}
This section presents the performance of the machine learning model used for crop recommendation based on soil health and environmental parameters. The evaluation focuses on how well the model predicts suitable crops using the processed dataset.

The model was assessed using standard classification metrics to determine its accuracy, consistency, and reliability. The results provide insight into the effectiveness of the model in identifying patterns within the dataset and generating accurate predictions.

\subsection{Model Configuration}
The TANIM crop recommendation system utilizes a Light Gradient Boosting Machine (LightGBM) classifier as its predictive engine. The selection of this algorithm was based on its computational efficiency, rapid execution speed, and robust capability to model nonlinear interactions inherent in complex agricultural datasets. By employing a gradient boosting framework that constructs decision trees leaf-wise rather than depth-wise, the algorithm achieves maximized classification accuracy while simultaneously minimizing memory overhead. This represents a critical architectural advantage for subsequent integration into resource-constrained Internet of Things (IoT) deployments. Functioning as a robust multiclass classifier, the system is designed to map environmental parameters collected in real time to the most agronomically suitable crop from a predefined selection.

The baseline input features ingested by the model are derived from critical soil physicochemical properties continuously collected via the sensor network. These include Organic Matter, expressed as a percentage and functioning as a proxy for Nitrogen; Phosphorus, measured in parts per million (ppm); Potassium, also in ppm; and soil pH levels. To augment the predictive depth of the system, a dedicated feature engineering pipeline introduces four derived agronomic features explicitly formulated to capture vital soil and crop interaction effects. These engineered variables encompass the Phosphorus-to-Potassium ratio ($P/K$), the Phosphorus-to-Organic Matter ratio ($P/OM$), and mathematical interaction terms between pH and nutrient availability, specifically $Organic\ Matter \times pH$ and $Potassium \times pH$. By synthesizing this set of eight total features, the model is equipped to discern profound agronomic phenomena, such as the manner in which pH variations modulate the physiological uptake of localized nutrients.

To ensure representational fairness and mitigate predictive bias, a rigorous data preprocessing pipeline has been implemented. Empirical agricultural datasets frequently exhibit class imbalances, where the profiles of certain prevalent crop varieties substantially outnumber those of minority varieties. To address this issue, a synthetic data augmentation technique utilizing K-Means Clustering is applied. This methodology identifies dimensional clusters within the minority classes and generates targeted localized synthetic samples infused with Gaussian noise, thereby achieving a smooth balancing of the dataset. Subsequent to augmentation, features undergo standardization, and the categorical crop targets are mathematically transformed utilizing label encoding.

Rather than relying on static heuristic parameters, the architecture of the classifier was systematically optimized using Bayesian hyperparameter optimization facilitated by the Optuna framework. The optimization process involved the execution of 50 independent trials evaluated under a rigorous five-fold stratified cross-validation protocol. This protocol ensured that the proportional representation of each crop class remained perfectly balanced across all training and holdout evaluation folds. The Optuna study was configured to minimize multiclass logarithmic loss by dynamically exploring an expansive parameter space. This optimization included parameters governing tree structural depth, specifically $max\_depth$ and $num\_leaves$; convergence pacing through $learning\_rate$; stochastic ensemble sampling techniques such as $feature\_fraction$ and $bagging\_fraction$ to counteract overfitting; and the fine-tuning of L1 and L2 regularization penalties, denoted as $\lambda_{l1}$ and $\lambda_{l2}$. The final model weights are a direct product of the parameters yielded by the best-performing trial.

Upon deployment, the model generates a probability distribution across all candidate crop categories, algorithmically isolating the highest-scoring outcome as the primary crop recommendation alongside a calculated prediction confidence percentage. This primary inference seamlessly informs a secondary subsystem responsible for generating actionable crop-specific fertilizer recommendations. These recommendations are strictly based on the discrepancies observed between the current soil state and the ideal agronomic conditions for the chosen crop. Notwithstanding the sophistication of this pipeline, the system operates under specific technical assumptions necessitated by hardware constraints. Principally, standard commercial soil sensors often estimate explicit Nitrogen, Phosphorus, and Potassium values indirectly through broad surrogate measurements, such as electrical conductivity. Consequently, these inputs function as highly correlated proxies rather than precise laboratory-grade chemical extractions. The model natively accommodates this hardware limitation by assuming that the measured Organic Matter and resultant electrical conductivity metrics constitute sufficient and consistent correlative indicators for localized soil fertility.

\subsection{Training and Validation Setup}
The foundation of the TANIM crop recommendation framework is based on an empirical dataset obtained from the Consolidated Soil Information (RSL) repository covering the years 2023 to 2025. The dataset includes key soil physicochemical properties such as nitrogen derived from organic matter, phosphorus, potassium, and soil pH, which are associated with historical crop suitability. These parameters serve as the ground truth for training the machine learning model and for validating the data collected from the Internet of Things sensing unit.

To systematically evaluate the predictive performance of the model, the dataset was divided into training, validation, and testing subsets using a 70 percent, 15 percent, and 15 percent split, respectively. A stratified sampling approach was applied to preserve the proportional distribution of crop classes across all subsets. This ensured that each crop category was properly represented during training, tuning, and final evaluation, thereby reducing sampling bias.

A common challenge in agricultural datasets is class imbalance, where widely cultivated crops are overrepresented compared to less common varieties. To address this, a localized oversampling technique based on K-Means clustering was applied to the training dataset. This method groups minority class samples and generates synthetic data points near cluster centroids using controlled perturbation. This improves class balance while preserving the structure of the original data, allowing the model to learn more effectively across all crop categories.

The model training process utilized a Light Gradient Boosting Machine algorithm, which was optimized using a Bayesian hyperparameter tuning framework implemented through Optuna. The optimization process consisted of 50 trials evaluated using five-fold stratified cross-validation within the training dataset. The validation subset was used to monitor model performance during tuning and to guide the selection of optimal hyperparameters. This approach ensured that the model achieved strong generalization while minimizing overfitting.

During optimization, key parameters such as learning rate, number of leaves, and tree depth were adjusted. Regularization techniques, including L1 and L2 penalties, were applied to control model complexity. In addition, feature sampling and data bagging were incorporated to improve robustness and prevent over-reliance on specific data patterns.

After determining the optimal hyperparameters, the final model was trained using a multiclass logarithmic loss objective function for up to 500 boosting iterations. An early stopping mechanism was implemented based on validation performance, where training was halted if no improvement was observed over 20 consecutive iterations. This ensured that the model parameters were captured at their optimal state without overfitting.

The final model was evaluated using the unseen 15 percent testing dataset. Performance was measured using multiple evaluation metrics, including accuracy, precision, recall, and F1-score. These metrics provided a comprehensive assessment of the model’s predictive capability across all crop classes. The results indicate that the model is capable of generating accurate and balanced crop recommendations, even in the presence of class imbalance within the dataset.

\subsection{Performance Metrics}
To rigorously quantify the operational efficacy of the crop recommendation engine, the Light Gradient Boosting Machine (LightGBM) classifier was evaluated against the unseen holdout subset utilizing a multidimensional array of statistical performance metrics. As illustrated in \textbf{Figure \ref{fig:classification_report}}, the model achieved a global accuracy of 83.2\%, providing a robust baseline for its predictive capability. While standard global accuracy offers a general understanding of the overall prediction rate, it can occasionally misrepresent true performance in agricultural datasets. Consequently, balanced accuracy was prioritized to establish an equitable metric, functionally calculating the macro-average recall across each crop category. This approach ensures that synthetically augmented minority classes are predicted with the same fidelity as natively dominant ones, maintaining the integrity of the recommendation engine across all ten targeted crops.

\begin{figure}[H]

To analyze prediction granularity, the evaluation extracted precision, recall, and the resulting F1-score for each crop type. Precision quantified the exact proportion of positive crop recommendations that were agriculturally correct, while recall measured the proportion of actual viable instances that the model successfully identified. These characteristics were harmonized into a weighted F1-score of 0.831, which serves as the definitive harmonic mean of the classifier. As shown in \textbf{Figure \ref{fig:classification_report}}, the model demonstrated exceptional performance for Tobacco, yielding a near-perfect F1-score of 0.965, whereas Eggplant proved more challenging with an F1-score of 0.664. Within the specific operating context of an agricultural Internet of Things (IoT) system, optimizing this F1-score is paramount; it guarantees that the operational and financial resources of the end user are not expended on false positive recommendations while ensuring that highly viable, niche crop opportunities are systematically identified. Furthermore, localized multiclass logarithmic loss was utilized as the mathematical penalty benchmark during the Optuna hyperparameter trials, penalizing the algorithm for false classifications at an intensity proportional to unwarranted model confidence.
